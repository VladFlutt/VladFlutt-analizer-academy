# Анализатор Academy — R&S FSL18

Учебная платформа по работе с анализатором спектра Rohde & Schwarz FSL18: теория, квизы, симулятор прибора с практическими заданиями и итоговый экзамен.

## Что внутри

- **Теория** — 10 модулей: принцип супергетеродинного анализатора, передняя панель, частота и уровень, RBW/VBW и развертка, трассы и детекторы, маркеры, измерения (CP/ACP/OBW/TOI/AM), расширенные функции, файлы и дистанционное управление. Со схемами.
- **Квизы** — по 10 вопросов на модуль с объяснениями.
- **Симулятор** — интерактивная передняя панель FSL18 (softkeys, функциональные клавиши, цифровая клавиатура, ручка — колесо мыши) с моделью шумов, RBW-фильтра, времени развертки, детекторов, перегрузки смесителя, гармоник и интермодуляции.
- **Задания** — 15 практических задач на симуляторе с автоматической проверкой.
- **Итоговый экзамен** — 20 вопросов + 2 практических задания, 45 минут, порог 80 %.
- **Словарь** — термины и сокращения курса с поиском. В уроках, тестах и заданиях термины подчёркнуты пунктиром: при наведении мыши (или нажатии на телефоне) всплывает короткое объяснение.
- **ИИ-наставник** — чат в углу любой страницы. Видит текущий урок, условие задания и настройки виртуального прибора и отвечает с учётом этого. После неудачной проверки задания кнопка «Разобрать ошибки с ИИ» объясняет, что не так и что нажать на панели (без готовых чисел ответа). В тесте у неверных ответов есть кнопка «Объяснить подробнее». Во время экзамена наставник отключён.
- **Результаты** — прогресс по модулям, что повторить, история экзаменов. Прогресс хранится в браузере (localStorage).

## Запуск локально

Сборка не нужна — это статический сайт на ES-модулях.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` напрямую из файловой системы нельзя: уроки загружаются через `fetch`.

## Деплой на Vercel

New Project → импортировать репозиторий → Framework Preset **Other**, без команды сборки, Output Directory — корень. `vercel.json` уже в репозитории.

### Ключ для ИИ-наставника

ИИ-функции работают через серверную функцию `api/ai.js` (Claude API). В Vercel откройте проект → Settings → Environment Variables и добавьте `ANTHROPIC_API_KEY` (ключ из console.anthropic.com), затем сделайте Redeploy. Без ключа сайт работает как раньше, а наставник отвечает, что не настроен. Проверить: `GET /api/ai` возвращает `{"configured": true}`.

Каждый вопрос к наставнику оплачивается по тарифам Claude API. Длина вопроса и контекста на сервере ограничена; лимит расходов задайте в консоли Anthropic.

## Деплой на Amvera или Layero

В репозитории есть `Dockerfile` (nginx отдаёт статические файлы на порту 80) и `amvera.yml`.

- **Amvera:** создайте приложение, подключите этот GitHub-репозиторий (или сделайте `git push` в репозиторий Amvera). Конфигурация возьмётся из `amvera.yml`, контейнер слушает порт 80.
- **Layero:** создайте проект из GitHub-репозитория, тип сборки Dockerfile, порт 80.

Контейнер отдаёт только статические файлы, поэтому ИИ-наставник на Amvera и Layero, как и в однофайловой версии, обращается к функции на `analizer-academy.vercel.app`. Другой адрес можно задать через `window.AI_ENDPOINT` в `index.html`.

## Структура

```
index.html, styles.css, favicon.svg
content/        уроки в Markdown
js/app.js       маршруты и страницы
js/data.js      модули, квизы, параметры экзамена
js/analyzer.js  модель анализатора
js/panel.js     передняя панель и экран
js/tasks.js     практические задания
js/figures.js   схемы для уроков
js/glossary.js  словарь и всплывающие подсказки
js/ai.js        ИИ-наставник, разбор ошибок, объяснения в тесте
api/ai.js       серверная функция Vercel для ИИ (Claude API)
js/md.js        рендер Markdown
```
