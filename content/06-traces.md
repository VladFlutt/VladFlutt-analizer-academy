# Трассы и детекторы

## Шесть трасс

R&S FSL показывает до **шести трасс** одновременно. Трасса состоит из 501 точки по умолчанию. Каждой трассе назначается свой режим и детектор.

Клавиша **TRACE** открывает меню трасс:

1. **Trace 1 2 3 4 5 6** выбирает активную трассу.
2. **Trace Mode** задаёт режим.
3. **Detector Auto Select** или **Detector Manual Select** задаёт детектор.
4. **Sweep Count** определяет число разверток для усреднения.
5. **Copy Trace** копирует трассу в другую память (копия переходит в режим View).
6. **ASCII File Export** сохраняет трассу в текстовый файл на флеш-диск или USB.

## Режимы трассы

| Режим | Что делает | Когда применять |
|---|---|---|
| **Clear Write** | Каждая развертка перезаписывает трассу (по умолчанию) | Обычные измерения |
| **Max Hold** | Хранит максимум по всем разверткам; детектор Pos Peak | Модулированные, импульсные, скачущие по частоте сигналы: спектр «заполняется» огибающей |
| **Min Hold** | Хранит минимум; детектор Neg Peak | Выделить немодулированную несущую среди шума и модулированных сигналов |
| **Average** | Усреднение по разверткам; детектор Sample | Сгладить шум, увидеть слабый стационарный сигнал |
| **View** | Замораживает трассу | Сравнение «до/после»; на экране слева от сетки метка `*` |
| **Blank** | Скрывает трассу | |

При смене режима память трассы очищается. В режиме View можно менять опорный уровень и диапазон: прибор перерисует сохранённые данные (амплитудный зум после измерения).

## Как работает усреднение

Пусть c — Sweep Count, n — номер развертки.

- Пока n ≤ c, показывается обычное среднее арифметическое всех выполненных разверток.
- После c разверток в непрерывном режиме идёт скользящее усреднение: новая трасса входит с весом 1/c.
- При Sweep Count = 0 используется скользящее усреднение с c = 10.
- При Sweep Count = 1 усреднения нет.

**Average Mode** определяет, что усредняется: LOG (значения в дБ), LIN (напряжения) или POWER (мощности). Усреднение в логарифмическом масштабе для шума даёт результат на 2,51 дБ ниже истинной мощности шума.

## Детекторы

Детектор решает, какое из многих измеренных значений внутри одной точки трассы показать на экране.

| Детектор | Метка | Значение в точке трассы |
|---|---|---|
| **Auto Peak** | Ap | Максимум и минимум (по умолчанию) |
| **Positive Peak** | Pk | Максимум |
| **Negative Peak** | Mi | Минимум |
| **Sample** | Sa | Одно случайное значение |
| **RMS** | Rm | Среднеквадратичная мощность |
| **Average** | Av | Линейное среднее напряжения |
| **Quasi Peak** | QP | Квазипиковое значение для ЭМС |

Все детекторы работают параллельно, поэтому скорость не зависит от их выбора.

## Какой детектор выбрать

- **Синусоидальный сигнал** (CW): любой детектор покажет одинаковый уровень, если RBW шире сигнала.
- **Шум**: Pos Peak завышает уровень, Neg Peak занижает. Для шума правильные результаты дают **RMS**, **Average** или **Sample с усреднением**.
- **Цифровые модулированные сигналы** (CDMA, OFDM, LTE): мощность в канале измеряют детектором **RMS**.
- **Поиск редких и коротких сигналов**: **Positive Peak** + **Max Hold**.
- **ЭМС-измерения по CISPR**: **Quasi Peak** с EMI-фильтрами.

> **Ловушка.** Детектор Sample при большом span и узкой RBW может «проскочить» узкий сигнал: в точку трассы попадает одна выборка, а сигнал оказался между выборками. Детектор Peak такой сигнал покажет.

## Автоматический выбор детектора

При **Detector Auto Select** детектор зависит от режима трассы:

| Режим трассы | Обычные фильтры | FFT-фильтры |
|---|---|---|
| Clear Write | Auto Peak | Max Peak |
| Average | Sample | Sample |
| Max Hold | Max Peak | Max Peak |
| Min Hold | Min Peak | Max Peak |

## Математика трасс

**Trace Math** вычитает одну трассу из другой, например *Trace 1 – Trace 2*. Так удобно сравнивать спектр «до» и «после» включения фильтра или видеть изменение уровня в дБ относительно сохранённой эталонной трассы.
