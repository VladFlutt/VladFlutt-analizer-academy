# Маркеры

## Маркеры и дельта-маркеры

Маркер ставит точку на трассе и выводит её уровень и частоту (или время в нулевом диапазоне). У R&S FSL **четыре маркера на трассу**.

- **Нормальный маркер** (M1) показывает абсолютные значения: уровень в дБм и частоту.
- **Дельта-маркер** (D2) показывает разность с маркером 1: Δуровень в дБ и Δчастоту.
- **Активный маркер** — тот, который сейчас двигается ручкой.
- **Временные маркеры** (T1…) появляются при работе функций (например, n dB down) и исчезают при их выключении.

Поле маркера в правом верхнем углу экрана показывает тип маркера, номер трассы, уровень и частоту, например:

    M1 [1]   -33.09 dBm
             3.000000000 GHz

## Клавиша MKR

При первом нажатии **MKR** включается маркер 1 и сразу ставится на максимум трассы.

| Программная клавиша | Назначение |
|---|---|
| **Marker 1…4** | Включить маркер. Маркеры 2–4 включаются как дельта-маркеры |
| **Marker Norm/Delta** | Переключить тип маркера |
| **Marker to Trace** | Перенести маркер на другую трассу |
| **All Marker Off** | Выключить все маркеры |
| **Sig Count On/Off** | Частотомер: точная частота сигнала у маркера |
| **Noise Meas On/Off** | Плотность мощности шума у маркера, дБм/Гц |
| **Phase Noise / Ref Fixed** | Фиксированная опорная точка; измерение фазового шума в дБн/Гц |
| **n dB down** | Полоса сигнала по уровню n дБ ниже пика (по умолчанию 3 дБ) |
| **Marker Zoom** | Растянуть область вокруг маркера |
| **Marker Peak List** | Таблица пиков трассы |
| **Marker Demod** | Прослушивание AM/FM-демодулированного сигнала в наушниках |

Маркер двигают ручкой, стрелками или вводом частоты с клавиатуры.

## Клавиша MKR→

**MKR→** выполняет поиск и меняет настройки прибора по маркеру.

| Программная клавиша | Назначение |
|---|---|
| **Peak** | Маркер на максимум трассы |
| **Next Peak** | На следующий по уровню пик (также Next Peak Left/Right) |
| **Min** | На минимум трассы |
| **Center =Mkr Freq** | Центральная частота = частота маркера |
| **Ref Lvl =Mkr Lvl** | Опорный уровень = уровень маркера |
| **Search Limits** | Искать пики только между Left Limit и Right Limit |
| **Peak Excursion** | Минимальный перепад, при котором пик считается отдельным (по умолчанию 6 дБ) |

> **Типовая последовательность.** Нашли сигнал на широком span → **MKR→ Peak** → **Center =Mkr Freq** → уменьшили span → снова **Peak**. Так сигнал «приближают», пока он не займёт нужную часть экрана.

## Частотомер

Маркер определяет частоту по положению точки на трассе, поэтому его погрешность зависит от span и числа точек: ±(½ · span / 500 + 10 % RBW + …). На span 100 МГц одна точка трассы — это 200 кГц.

**Sig Count** останавливает развертку в точке маркера, измеряет частоту на ПЧ и пересчитывает её во входную частоту. Разрешение 1 Гц, погрешность определяется только точностью опорного генератора. Для измерения нужно отношение сигнал/шум больше 25 дБ.

## Плотность шума

**Noise Meas** показывает уровень шума у маркера в пересчёте на полосу **1 Гц** (дБм/Гц).

Как прибор это считает:

- включает детектор Sample, VBW = RBW/10;
- усредняет 17 соседних точек трассы (маркер и по 8 слева и справа);
- добавляет 2,51 дБ (поправка на логарифмическое усреднение шума);
- вычитает 10·lg(RBW шумовая), чтобы привести результат к 1 Гц.

Пересчёт в другую полосу: прибавьте 10·lg(BW). Например, –150 дБм/Гц в полосе 1 кГц: –150 + 30 = **–120 дБм**.

> **Важно.** Детекторы Pos Peak, Neg Peak, Auto Peak и Quasi Peak для измерения шума не подходят. С детектором RMS не включайте усреднение трассы: увеличьте время развертки.

## Фазовый шум и опорная точка

**Phase Noise / Ref Fixed** фиксирует уровень и частоту маркера 1 как опорную точку и включает дельта-маркер.

- В режиме **Phase Noise** дельта-маркер показывает уровень шума относительно несущей в **дБн/Гц** на заданной отстройке.
- В режиме **Ref Fixed** дельта-маркер показывает разность в **дБ**. Так удобно измерять гармоники: опорная точка на основной частоте, дельта-маркер на гармонике.

Пример: несущая 100 МГц, 0 дБм, span 50 кГц, отстройка 10 кГц. После **TRACE → Average** результат стабилизируется, и дельта-маркер покажет фазовый шум в дБн/Гц.

## Полоса по уровню n дБ

**n dB down** ставит два временных маркера слева и справа от пика на уровне на n дБ ниже и показывает расстояние между ними. Так измеряют полосу фильтра по уровню –3 дБ или ширину сигнала. Значение n можно изменить.
