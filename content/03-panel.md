# Передняя панель и экран

## Органы управления

Передняя панель R&S FSL делится на несколько зон.

[[fig:panel]]

| Зона | Клавиши | Назначение |
|---|---|---|
| Системные | **PRESET**, **FILE**, **SETUP**, **PRINT** | Сброс настроек, файлы, системные и сервисные настройки, печать |
| Режим | **MODE**, **MENU** | Выбор режима измерения (анализатор спектра, опции K…) и его меню |
| Параметры измерения | **FREQ**, **SPAN**, **AMPT**, **BW**, **SWEEP**, **TRIG**, **TRACE** | Частота, полоса обзора, уровень, полосы фильтров, развертка, запуск, трассы |
| Функции измерения | **MKR**, **MKR→**, **MEAS**, **LINES** | Маркеры, действия по маркеру, измерения мощности, линии допуска |
| Ввод данных | Цифровая клавиатура, клавиши единиц, **ENTER**, **ESC**, стрелки, вращающаяся ручка | Ввод значений и навигация |

**Программные клавиши** (softkeys) расположены справа от экрана. Их назначение меняется: каждое нажатие функциональной клавиши (например, **FREQ**) открывает своё меню. Клавиша **⯅** (Menu Up) возвращает к предыдущему уровню меню.

## Ввод значений

Почти каждая клавиша открывает окно ввода главного параметра: **FREQ** — центральная частота, **SPAN** — полоса обзора, **AMPT** — опорный уровень.

Значение можно задать тремя способами:

1. **Цифровой клавиатурой** с клавишей единиц: `1` `2` `8` и **MHz**. Клавиши единиц двойные: **GHz / −dBm**, **MHz / dBm**, **kHz / dB**, **Hz / dB**. Для уровня нажимают **dBm** или **−dBm**.
2. **Вращающейся ручкой**: плавное изменение. Шаг ручки равен 1/10 шага стрелок.
3. **Стрелками ⯅ ⯆**: изменение на заданный шаг. Для центральной частоты шаг задаёт **CF Stepsize** (по умолчанию 10 % от span).

**ESC** закрывает окно ввода без изменений, **ENTER** подтверждает значение в базовых единицах (Гц, дБм).

## Экран измерения

[[fig:screen]]

| Элемент | Что показывает |
|---|---|
| **Ref** | Опорный уровень (верхняя линия сетки) |
| **Att** | Ослабление ВЧ-аттенюатора |
| **RBW**, **VBW** | Полосы разрешения и видеофильтра |
| **SWT** | Время развертки (у FFT-фильтров **AQT**, время сбора) |
| Зелёная звёздочка `*` | Параметр задан вручную, а не связан автоматически |
| Красная звёздочка `*` у SWT | Время развертки слишком мало, уровни неверны (UNCAL) |
| Поле маркера | Тип маркера (M1, D2), трасса [1], уровень и частота |
| Информация о трассе | Номер, детектор (Ap, Pk, Sa, Rm…) и режим трассы (Clrw, Avg, Max…) |
| Метки справа | OVLD, IFOVL, UNCAL, GAT и др. |
| Подпись снизу | Center и Span (или Start и Stop) и цена деления |

Сетка по вертикали имеет 10 делений. По умолчанию диапазон отображения 100 дБ, то есть 10 дБ на деление.

## Исходное состояние PRESET

Клавиша **PRESET** возвращает прибор в известное исходное состояние. С него начинается почти каждое измерение и все примеры в руководстве.

| Параметр | Значение после PRESET (FSL18) |
|---|---|
| Режим | Spectrum Analyzer |
| Центральная частота | fmax / 2 = **9 ГГц** |
| Шаг центральной частоты | 0,1 × центральная частота |
| Span | **18 ГГц** (полный диапазон) |
| Ослабление ВЧ | Auto (**10 дБ**) |
| Опорный уровень | **–10 дБм** |
| Диапазон уровней | 100 дБ, логарифмический |
| Единица уровня | дБм |
| RBW | Auto (**3 МГц**) |
| VBW | Auto (**10 МГц**) |
| Связь span/RBW и RBW/VBW | 50 и 0,33 |
| Время развертки | Auto |
| Развертка | Непрерывная (cont) |
| Запуск | Free Run |
| Трасса 1 | Clear Write; трассы 2–6 выключены (Blank) |
| Детектор | **Auto Peak** |
| Вход | RF; следящий генератор выключен |

> **Совет.** Набор настроек для PRESET можно заменить своим файлом: **FILE → Startup Recall**. Но для учёбы и в незнакомой ситуации лучше пользоваться заводским состоянием.

## Внутренний калибровочный сигнал

Для тренировки без генератора у FSL есть внутренний опорный сигнал **65 МГц**:

1. **SETUP → Service**.
2. Нажимайте **Input RF/Cal/TG**, пока не выделится **Cal**. ВЧ-вход при этом отключается.
3. Чтобы вернуть обычную работу, нажмите **PRESET** или выберите **RF** той же клавишей.

Этот сигнал удобен для первых упражнений: найти пик, измерить частоту и уровень маркером.

## Встроенная справка

Чтобы узнать назначение любой программной клавиши, нажмите **HELP**, а затем эту клавишу. Окно справки закрывается клавишей **ESC**.
