# Файлы, настройки и дистанционное управление

## Сохранение и загрузка: клавиша FILE

Прибор хранит больше 500 наборов настроек и трасс на внутреннем флеш-диске или USB-накопителе.

| Задача | Действия |
|---|---|
| Сохранить настройки | **FILE → Save**, ввести имя, **Save File**. По умолчанию трассы не сохраняются |
| Сохранить с трассами | **FILE → Save → Select Items**, отметить **All Traces** |
| Загрузить | **FILE → Recall**, выбрать файл, **Recall File** |
| Загружать при PRESET | **FILE → Startup Recall** On и **Startup Recall Setup**: выбрать файл |

Папка по умолчанию: `C:\R_S\Instr\user`.

Чтобы сохранить текущие настройки при выключении, переведите прибор в режим ожидания клавишей **ON/STANDBY** и дождитесь жёлтого индикатора: создастся файл завершения работы.

**PRINT** сохраняет снимок экрана в файл или печатает его на принтере.

## Клавиша SETUP

| Пункт | Назначение |
|---|---|
| **Reference Int/Ext** | Внутренний или внешний опорный сигнал 10 МГц. Без внешнего сигнала — метка **EXREF** |
| **Transducer** | Таблицы поправок (антенны, кабели, пробники) |
| **General Setup** | Сетевые настройки, GPIB-адрес, дата и время, цвета экрана |
| **System Info** | Версии прошивки, опции, температура |
| **Service** | Самопроверка, калибровка, переключение входа **RF / Cal / TG** |
| **Alignment** | Самоподстройка прибора |

> **Внутренний сигнал 65 МГц.** SETUP → Service → Input RF/Cal/TG до выделения **Cal**. Возврат: PRESET или выбрать **RF**.

## Следящий генератор

У моделей .13, .16 и .28 есть **следящий генератор** (TG). Он выдаёт синусоиду, частота которой в каждый момент совпадает с частотой, на которую настроен анализатор. Подключив TG ко входу тестируемого устройства, а его выход ко входу анализатора, получают **АЧХ** (передаточную характеристику) фильтра, усилителя или кабеля.

У FSL18 TG работает от 10 МГц до 18 ГГц, мощность –30…0 дБм шагами по 10 дБ. Перед измерением выполняют **нормализацию**: соединяют TG напрямую со входом, запоминают «прямую линию» и дальше показывают только характеристику DUT. Динамический диапазон для развязки до 80 дБ (10 МГц – 2 ГГц).

С включённым TG FFT-фильтры недоступны.

## Дистанционное управление

Прибором можно управлять с компьютера через **LAN** (протоколы VXI-11 и RSIB) или **GPIB** (опция B10). Команды записываются в формате **SCPI**.

| Действие | Команда SCPI |
|---|---|
| Сброс (как PRESET) | `*RST` |
| Идентификация | `*IDN?` |
| Центральная частота | `FREQ:CENT 100MHz` |
| Span | `FREQ:SPAN 2GHz` |
| Start / Stop | `FREQ:STAR 20MHz`, `FREQ:STOP 2000MHz` |
| Опорный уровень | `DISP:TRAC:Y:RLEV -60dBm` |
| Ослабление | `INP:ATT 30 DB`, `INP:ATT:AUTO ON` |
| RBW, VBW | `BAND 10kHz`, `BAND:VID 1kHz` |
| Однократная развертка с ожиданием | `INIT:CONT OFF; INIT; *WAI` |
| Маркер на пик и чтение | `CALC:MARK:MAX`, `CALC:MARK:X?`, `CALC:MARK:Y?` |
| Ошибки | `SYST:ERR?` |

Пример короткой программы:

    *RST
    FREQ:CENT 1GHz
    FREQ:SPAN 10MHz
    BAND 10kHz
    INIT:CONT OFF
    INIT;*WAI
    CALC:MARK:MAX
    CALC:MARK:Y?

## Правила SCPI

- Команды иерархические: части разделяются двоеточием (`FREQ:CENT`).
- Можно писать коротко (заглавные буквы) или полностью: `FREQ:CENT` = `FREQuency:CENTer`.
- Запросы оканчиваются на **?** и возвращают значение.
- Общие команды IEEE 488.2 начинаются со звёздочки: `*RST`, `*IDN?`, `*OPC?`, `*WAI`.
- Несколько команд в одной строке разделяют точкой с запятой.

В режиме дистанционного управления клавиши передней панели заблокированы. Вернуться к ручному управлению можно программной клавишей **Local** (если не включён **LOCAL LOCKOUT**).
